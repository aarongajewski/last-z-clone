# Credits

## Art

**Kenney — Topdown Shooter (1.0)**, CC0 1.0 Universal (public domain). https://kenney.nl/assets/top-down-shooter

- Soldiers, zombies, the boss, hero portraits, weapons, crates, and barrels in `public/assets/kenney/atlas.png`.
- Fetched from the Git LFS mirror [series-ai/jam-ready-assets](https://github.com/series-ai/jam-ready-assets)
  at commit `2d7c41049c1db4d670b1ded88a7aeec0d7c2f38c`, path `kenney-topdown-shooter/2D/misc/`
  (kenney.nl is not reachable from the build workers). The pack's own `License.txt` is kept as
  `public/assets/kenney/LICENSE-kenney.txt`.
- Characters are rendered from the pack's vector file at 2x-4x by `scripts/import-kenney.mjs`;
  the boss is the second zombie with a hue shift. The script records the exact frames used.

Everything else on screen (road, gates, barricade bases, tracers, grenades, pickups, particles,
hero skill glyphs, shelter building icons, app icons, splash screens) is drawn procedurally at
boot in `src/game/textures.ts` or generated by `scripts/make-icons.mjs`.

## Audio

All sound effects and the music loop are synthesised at runtime with the Web Audio API in
`src/audio/AudioEngine.ts`. No audio files are shipped.
